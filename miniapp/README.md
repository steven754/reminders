# 日常提醒微信小程序

这是 `reminders` 的原生微信小程序源码，直接调用同一套 Go API，不另建数据库。

## 导入

1. 使用微信开发者工具打开本目录 `miniapp/`。
2. 修改 `utils/config.js` 的 `baseUrl`。
3. 本地联调可在开发者工具中勾选“不校验合法域名、TLS 版本以及 HTTPS 证书”。
4. 正式发布前，后端必须使用 HTTPS 域名，并把该域名加入微信公众平台的 request 合法域名。

登录使用提醒中心已有的应用账号；一次性提醒使用日期+时间，循环提醒使用单位和数值分开的可视化间隔选择，
也支持自定义 Cron、结束时间和多选通知渠道，所有数据都保存到现有后端数据库。

## API 地址

`baseUrl` 只填写协议和域名/端口，不要以 `/` 结尾，例如：

```js
baseUrl: 'https://reminders.example.com'
```

小程序不能直接使用 `192.168.x.x` 地址上线；局域网调试时可以在开发者工具里使用 NAS 地址。
